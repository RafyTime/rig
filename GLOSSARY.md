# Rig

Rig is Leo's shared personal configuration repository.

## Language

**Skill selection**:
The sources and named skills, downloaded or custom, the user wants available across devices.

**Downloaded skill**:
A skill obtained from an upstream source whose content remains maintained upstream.

**Custom skill**:
A skill whose content the user owns and maintains, including an intentionally customized downloaded skill.

**Installed copy**:
The local instruction or skill files an agent reads on a device.

**Sync**:
Bringing a device's installed setup into agreement with the shared configuration and skill selection.

**Skill update**:
An intentional refresh of a selected downloaded skill from its upstream source.

**Unlisted skill**:
An installed skill that is absent from the shared skill selection and remains outside its management.
